# Software Delivery Governance

![Validation CI](https://github.com/visionarycoder/vc.Governance/actions/workflows/software-delivery.yml/badge.svg)


This folder contains the **process‑only** governance artefacts for the VBD software delivery pipeline. It defines roles, workflows, decision‑record templates, and validation tooling.

## Quick start
- Run the validator and link checker from the repository root as shown in [ONBOARDING.md](ONBOARDING.md).
- Follow the steps in `ONBOARDING.md` to set up the CI badge and add new decision records.
