# Activities and Dependencies

## Goal
Convert approved change requirements into schedulable work without inventing technical content.

## PM instructions
1. Collect required work from the authoritative owners.
2. Define an activity for each independently completable work effort.
3. Identify the artifact or outcome produced by each activity.
4. Identify prerequisites and downstream dependents.
5. Identify the responsible agent address.
6. Detect work that would modify the same authoritative artifact and sequence it.
7. Preserve owner-defined acceptance criteria.
8. Do not collapse independent ownership boundaries merely to simplify scheduling.

## Output
Activities and explicit dependencies suitable for the project network.
