# Effort Estimation

## Goal
Estimate the delivery effort for defined activities without changing their technical scope.

## PM instructions
- Estimate only after the relevant authority has defined the work sufficiently.
- Record assumptions with the estimate.
- Treat uncertainty as visible project information.
- Request clarification when an activity cannot be estimated responsibly.
- Re-estimate when approved scope or dependencies change.

## Constraint
An estimate does not authorize the PM to reduce requirements or alter architecture. Scope changes return to the appropriate owner.
