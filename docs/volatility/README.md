# Volatility Analysis

This folder contains JSON reports generated by the **Volatility Analyzer** tool. Each report (`volatility-analysis-<gate>.json`) records the identified change drivers for a gate and any boundary violations detected.

The governance validator reads these files to ensure that no uncaptured volatility crosses component boundaries, as required by Juval Lowy’s *The Method*.
