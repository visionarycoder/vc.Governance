# Definition of Done

Developer implementation is ready for acceptance only when:

- [ ] The assigned requirement is correctly implemented.
- [ ] The approved Detailed Design and contracts are respected.
- [ ] No unauthorized artifact was modified.
- [ ] Relevant unit tests were created or updated.
- [ ] All affected unit tests pass.
- [ ] SA-defined coverage requirements are met.
- [ ] Build, analyzer, and formatting checks pass.
- [ ] Security and compatibility impacts were addressed.
- [ ] Surface Area and implementation documentation were updated.
- [ ] Required decision records exist.
- [ ] The work item identifies the changed artifact revisions.
- [ ] No unresolved blocking message remains.
