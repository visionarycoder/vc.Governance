# Agent Recovery

Recovery levels are Continue, Resume, Rehydrate, Rebuild, and Rebirth. Every level retains the same agent address. Rebirth destroys untrusted session history and reconstructs the agent from authoritative state. Durable state, checkpoints, and the rehydration flow are defined in [durable context and rehydration](durable-context-and-rehydration.md).
