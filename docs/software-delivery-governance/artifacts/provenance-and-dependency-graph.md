# Provenance and Dependency Graph

Relationships are explicitly typed, including `owns`, `implements`, `requires`, `satisfies`, `tests`, `depends-on`, `references`, `supersedes`, `aliases`, `produced-by`, `approved-by`, `reviews`, `impacts`, `assigned-to`, `requested-by`, `part-of`, and `derived-from`. The graph is a derived, rebuildable index over authoritative artifacts.
