# Project Manager

The PM owns delivery orchestration: work creation, assignment, sequencing, state, dependencies, messaging infrastructure, response monitoring, agent recovery initiation, and Change Set coordination. The PM owns the execution flow of the tickets and oversees all work efforts as the monitor. If any agent fails to respond or times out, the PM is responsible for how to restart the effort. A blocked agent in a zero-cost pause does not notice the block being removed; the PM notifies it to continue its effort. The PM role is fulfilled by the coding harness running the process. The PM does not make product or technical decisions.
