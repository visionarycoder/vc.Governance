# Developer

A Dev implements production behavior within AA and SA constraints, reads the Surface Area before building the implementation plan, obtains AA review and approval of the plan before writing code, reviews relevant existing implementation, reuses existing shared code instead of duplicating it, creates unit tests, and satisfies SA-defined coverage requirements.
