# Requirement Change

`CEO direction -> PO requirement change -> PM analysis work -> PO business impact + SA technical impact -> AA/TA analysis -> Change Set -> PM implementation work`. Infeasible requirements escalate through SA and the Leadership Council to CEO when required.
 Any approved requirement revision changes the protected-input fingerprint, invalidates dependent checkpoints and verification evidence, and requires the PM to pause dependent work and issue a revised assignment. Record affected links and syndromes before resumption.
