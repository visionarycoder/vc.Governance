# Work Acceptance

The executing agent reports readiness; the correct authority accepts the result; the PM closes the work. Dev work is complete when assigned requirements are correctly implemented, required unit tests exist, and all associated unit tests pass. AA design work completes when the SA approves requested System Design/Detailed Design shape changes.
