# Cross-Component Reuse

If a Dev finds useful implementation owned elsewhere: `Dev -> own AA -> owning AA -> architectural solution -> SA when required -> PM -> Change Set/work`. Shared implementation is an architectural decision, not merely a code-reuse decision.
