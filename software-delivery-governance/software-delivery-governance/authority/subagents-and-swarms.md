# Subagents and Swarms

An owner may create subagents or swarms for parallel analysis and execution. A subagent does not acquire independent ownership authority. Subagents produce proposed outputs for the parent owner. The parent remains accountable and presents one authoritative result.

Parallelism across independent artifacts is encouraged. Concurrent conflicting modification of one authoritative artifact is prohibited.
