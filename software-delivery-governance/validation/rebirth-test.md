# Rebirth Test

> [!question] Rebirth Test
> If an agent's entire session history were destroyed and the agent recreated from birth, could it reconstruct everything required to perform its role correctly from authoritative state?

If not, critical knowledge is trapped in ephemeral state and must become an authoritative artifact.
